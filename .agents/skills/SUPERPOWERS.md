# Superpowers project skills

Installed from [obra/superpowers](https://github.com/obra/superpowers),
revision `22f0b463e7a5e579904dd6211a520321035526f7`.
The upstream MIT license is retained in `SUPERPOWERS-LICENSE`.

The 15 upstream skills and their supporting files are installed in this
directory. Start with `using-superpowers/SKILL.md` to navigate the collection.
This is a project-local installation, not a global plugin installation.

## Replit compatibility

- Read applicable skill documents with the available file tools. Instructions
  mentioning a `Skill` tool do not require that unavailable tool.
- Replit's system instructions, task approvals, tool availability, and user
  requests take precedence over upstream workflow instructions.
- Do not automatically spawn agents, create worktrees, or request code reviews
  simply because an upstream skill recommends them. Follow the host's rules.
- Use Replit's existing project-task workflow for requested plans.
- No upstream startup hooks, plugin commands, or background services were
  installed. Bundled helper scripts are available as source, not auto-executed.
- This installation does not change application behavior, authentication,
  permissions, database contents, or deployment configuration.

## Updating

Review the upstream revision and changes first. Update only the directories
belonging to this collection, preserve unrelated project skills, retain the
license, and update the revision above. Do not run a remote installation script.
