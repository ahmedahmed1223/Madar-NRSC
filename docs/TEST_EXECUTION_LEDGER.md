# سجل تنفيذ خطة الاختبار

تاريخ التنفيذ: 2026-10-05. الاختبارات على قواعد بيانات معزولة؛ لم تتغير بيانات تشغيل المستخدم أو نموذج الخبر المفتوح على المنفذ 3000.

## الأوامر والأدلة

- `npm run typecheck`: ناجح.
- `npm run build`: ناجح.
- `npm test` بعد الإصلاحات وتوسيع التغطية: 205/205 ناجحة في 32 ملفاً. أصلح رفض رفع الملفات ذي الحجم المعلن وغير المعلن دون `ECONNRESET`.
- مجموعة التعاون الجديدة `collaborationRaces.test.ts`: 14/14 ناجحة. تشمل حدود إنشاء الأخبار للحسابات العشرة، وسباق الحجز والبث، وحدود طلب الصوت، وسحب الصلاحيات أثناء جلسة قائمة. هذه اختبارات ضمن مجموعة 205 وليست إضافة إلى العدد.
- إعادة المسارات على البناء النهائي: 52/52 ناجحة في جولة واحدة؛ الأمر `npx playwright test --grep-invert 'no WCAG A/AA'`. فحوص الوصول الثلاثة نجحت في الجولة الشاملة السابقة. ليست هذه نتيجة تشغيل أخير واحد بـ55/55.
- أُثبت فشل تركيز البحث بعد اختفاء زر عرض المزيد، ثم نجح الاختبار بعد إعادة التركيز إلى حقل البحث. نجح النوع والبناء على النسخة النهائية.

## مطابقة خطة التعاون مع التنفيذ

«جزئي» يعني نجاح اختبارات المكونات المذكورة، وليس تنفيذ الرحلة الجماعية كاملة.

| الحالة | الدليل المنفذ | التغطية |
|---|---|---|
| TEAM-01 | `multiUser.test.ts`: رفض تعارض الإصدار، اتساق كتّاب متعددين؛ `newsroom.test.ts`: مالك قفل واحد ومنع حفظ الزميل؛ `collaboration.spec.ts`: حلقة للقراءة لدى زميل حتى مغادرة المالك | ناجح في الحالات المذكورة؛ ليس اختبار حفظ الخبر نفسه عبر متصفحين |

| TEAM-03 | اختبارات دورة الخبر والتحرير والمراجعة؛ مسار إعادة المادة مع تعليق يحتاج رحلة كاملة | جزئي |
| TEAM-04 | `requests.test.ts`: طلب مونتاج، قبول وإنجاز، إشعار الطالب، ومنع جاهزية الحلقة غير المكتملة | جزئي؛ لم تنفذ الرحلة كلها عبر واجهات المنتج وMEDIA |

## حدود قبول الأدوار

اختبارات المتصفح تشمل الدخول والتنقل لعشرة أدوار وقيود واجهة محددة. أضيفت حماية حدود الإنشاء عبر API لكل حساب. نجحت استعادة مسودات الضيف والبرنامج والتغطية وإنشاء الحلقة بعد الرجوع والتحديث دون إنشاء سجل، والتحذير عند فشل التخزين المحلي. لا تعادل هذه الاختبارات تنفيذ الحالات الخمسين الخاصة بالأدوار أو تكرار جميع حالات COMMON لكل دور. الأدوار المخصصة، جميع أقسام الطاقم، الشبكة البطيئة وتجربة قارئ الشاشة تحتاج جولات إضافية.

لا فشل متبقياً في الجولات الآلية النهائية المذكورة. لا اعتماد إطلاق شامل قبل استكمال الحالات الحرجة الناقصة والاختبارات البشرية.
