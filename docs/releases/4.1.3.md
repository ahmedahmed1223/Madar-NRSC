# مدار v4.1.3

20 نوفمبر 2026

- فحص الإصدارات وتحميل الواجهة بعد نشر إصدار جديد من «ما الجديد». عند تهيئة وجهة نشر، يمكن لمدير النظام إرسال طلب النشر عبر GitHub Actions أو خدمة HTTPS موقّعة. يرفض مدار الطلب أثناء البث النشط. [إعدادات التحديث](../PRODUCTION_OPERATIONS.md#in-app-updates)
- يُعامل فيديو الفقرة الموجود في سلة المحذوفات كمادة مفقودة عند التحقق من الجاهزية.
- ينتظر تغيير حالة الحلقة تأكيد الخادم قبل السماح بتغيير آخر.
- يمر النقر عبر جسم الإشعار العابر حتى تبقى أزرار العمل متاحة.
- يشمل اختبار المناوبة إعداد حلقة ونشرة بالتوازي، وتعطل تكليف وإعادة إسناده حتى الإنجاز، والتحقق من نص الحلقة لدى المقدم والاستديو، ثم تسجيل انتهاء البث داخل مدار.
