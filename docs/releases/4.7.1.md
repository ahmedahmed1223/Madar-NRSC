# مدار v4.7.1

## غرفة الأخبار والبث

- يحتفظ المتصفح بالتعديلات المعلّقة لكل موظف على الأجهزة المشتركة، ويُظهر رسالة واضحة عند تعذّر التخزين المحلي.
- تستعيد قائمة الأخبار موضع التمرير والصفحة المختارة عند العودة من المحرر. ويستعيد زر النسخ التركيز بعد نسخ ملاحظة أو مهمة أو ملخص تسليم داخل إطار مضمّن.
- تتيح شاشة انقطاع الاتصال فتح وضع الهواء المُجهّز مسبقًا. وتحافظ ذاكرة التطبيق المؤقتة على ملفات الإصدار الجاري والسابق لدعم التبويبات المفتوحة أثناء التحديث.
- تحدّث الواجهة المجموعات التي تغيّرت، ويعتمد النشر المجدول على فهرس مخصّص في SQLite وPostgreSQL.

## إدارة النظام والتحديث

- يفصل البناء ملفات الخادم عن جذر الويب. في التثبيت اليدوي احتفظ بمجلدي `dist/` و`dist-server/` وشغّل `npm start` من جذر التطبيق.
- تستخدم صورة Docker الإصدار Node.js 26.13.1 LTS. ويبدأ إعداد Compose الجديد بـPostgreSQL 19.0 افتراضيًا. يحتفظ التحديث بمحرك القاعدة المستخدم حاليًا. [تشغيل الصورة](../PRODUCTION_OPERATIONS.md#database-engine-selection-and-switching)
- تحسّنت قيود الاتصالات الخارجية والاستعلامات الإدارية وتأكيد تنزيل القاعدة. يدعم النظام تشفير الأسرار الموجودة وتدوير مفتاحها بعد ضبط `STORED_SECRETS_KEY`. [إعداد التشفير والاستعادة](../STORAGE.md)
- يحتفظ التحديث بـ`DATA_DIR` والمرفقات والإعدادات، ويضيف الفهارس عبر ترحيل المخطط عند تشغيل الإصدار الجديد. تحفظ النسخ المحلية والخارجية المكتملة للمراجعة والاستعادة وفق إعدادات الاحتفاظ. [دليل النشر والنسخ الاحتياطي](../PRODUCTION_OPERATIONS.md)
