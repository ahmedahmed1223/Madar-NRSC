# Release 3.25.0

Date: 2026-10-10.

## Features

- Guest contact ownership and technical checks, confirmed saving and non-blocking readiness warnings.
- Searchable written pronunciation dictionary with server-stamped audit metadata and bounded Arabic matching.
- Reference notes in news/episode editors, stable teleprompter controls and encrypted offline preparation snapshots. Legacy version-1 packets remain readable.
- Immutable correction records with current-version authorization, payload-bound retries, transactional audit and deduplicated responsible-recipient notifications.
- Linked correction badges and help. Recording a correction never updates linked script bytes, approval or broadcast state automatically.

## Verification

TypeScript, 312/312 unit/server tests across 67 files and production build passed after the final review fix pass. A single serial Playwright invocation passed 30/30 focused journeys in 1.9 minutes, including 390px/1440px, light/dark accessibility, dictionary concurrent edit/delete preservation, stable prompter reference space/keyboard, offline encrypted reopening and editor role regressions. This is not a claim that the entire browser suite was run. No live destructive database tests were used.

## Final Review

One independent whole-branch review identified four release-blocking findings, all reproduced and fixed with RED/GREEN coverage: hidden correction data in rejected generic-sync responses; stale dictionary drafts overwriting or resurrecting entries; Space on pronunciation disclosure controlling playback; and dictionary activation resizing the reading viewport. No declined-to-judge behaviors or deferred minor findings were reported.

## Execution Decisions

- Use the approved existing feature checkout, not another worktree. Cost: no separate checkout isolation; test databases remain isolated.
- Existing offline proof authenticates packet identity, not all reference content. Notes remain encrypted reading references, never mutation authority. Cost: references are not a signed editorial dictionary archive.
- Commit the shared registry/policy/API changes for tasks 1-5 together after their individual checks. Cost: less granular feature bisecting, while retaining a buildable dependency-consistent commit.
- User's latest instruction authorizes main integration and a minor version bump beyond the original plan's integration exclusion. Remote publication is separate from changing the local release number.
