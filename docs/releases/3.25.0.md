# Release 3.25.0

Date: 2026-10-27. Quick access from the unified search (Ctrl+K).

- With an empty query the search lists «فتح مؤخراً» (the last 8 records opened from it, per user, in this browser), a «خبر جديد» action for users with `news.create`, and the screens the user may open.
- Typing a screen name or keyword (for example «الورديات») offers the screen after the record results; screens hidden by permission never appear.
- Recent entries refresh their titles from live data and drop deleted records; «مسح السجل» clears them. Stored values are sanitized, so a corrupted entry cannot break the dialog.
- The sidebar and the search share one screen-permission list (`src/shared/commandPalette.ts`).
- What's New, package, server health and rehearsal report versions match 3.25.0.

Verification: TypeScript, unit tests and production build passed; browser journeys for search, keyboard, navigation, workflow and WCAG A/AA accessibility (day, night, phone) passed.
