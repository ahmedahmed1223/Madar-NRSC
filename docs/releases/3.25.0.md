# Release 3.25.0

Date: 2026-10-28. Quick access from the unified search (Ctrl+K), dependency and runtime upgrade, and an Impeccable UI audit.

- With an empty query the search lists «فتح مؤخراً» (the last 8 records opened from it, per user, in this browser), a «خبر جديد» action for users with `news.create`, and the screens the user may open.
- Typing a screen name or keyword (for example «الورديات») offers the screen after the record results; screens hidden by permission never appear.
- Recent entries refresh their titles from live data and drop deleted records; «مسح السجل» clears them. Stored values are sanitized, so a corrupted entry cannot break the dialog.
- The sidebar and the search share one screen-permission list (`src/shared/commandPalette.ts`).
- Runtime: Node.js 24 LTS (Docker `node:24-trixie-slim`, CI), engines `>=22.12.0`. Express 5, Vite 8 (Rolldown), TypeScript 7 (non-strict settings kept explicitly), latest React, Vitest, Playwright and the rest; GitHub Actions v7.
- Express 5 adjustments: named catch-all route, empty-object `req.body` for bodiless API requests, string route params, and `dotfiles: 'allow'` for server-built file paths (backups, uploads, SPA fallback) so a hidden `DATA_DIR` keeps working.
- Impeccable audit (axe-core + rendered measurements on news list, editor, bookings, on-air and dashboard, desktop/phone, light/dark): 3 WCAG 2.2 target-size violations fixed (now 0), 10px text raised to 11px, monospace removed from Arabic counters, bookings details moved to the shared Modal, Ctrl+K badge no longer wraps or clips. The Impeccable skill and agents are vendored in `.claude/` (hooks not enabled).
- Episode blocker «معالجة النقص» now focuses the segment script or video field (FormPage's first-field focus no longer wins the race), which also stops later browser tests failing on a leftover edit lock.
- What's New, package, server health and rehearsal report versions match 3.25.0.

Verification: TypeScript, unit tests and production build passed; browser journeys for search, keyboard, navigation, workflow and WCAG A/AA accessibility (day, night, phone) passed.
