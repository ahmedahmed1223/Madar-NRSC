# مدار v4.3.3

- يمكن لمسؤول النظام فتح المعالج من «الإعدادات ← البيانات ← فتح معالج الإعداد» في أي وقت، بما في ذلك بعد حذف كل الأمثلة المتاحة.
- يفتح الزر خطوة المؤسسة ويعرض الاسم والقناة والتوقيت المحفوظ.
- تبيّن صفحة البيانات أنواع الأمثلة المتاحة للحذف وإعدادات المؤسسة المحفوظة، ويكون زر الحذف متاحًا عند وجود سجلات محددة وكتابة التأكيد.
- تقلّ المسافة قبل حقل عنوان الخبر في محرر الهاتف، ويسهل الوصول إليه عند فتح خبر للتحرير.
