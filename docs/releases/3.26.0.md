# Release 3.26.0

Date: 2026-10-28. UI/UX pass from a newsroom walkthrough (editor, journalist, producer; desktop and phone) and an Impeccable critique, plus the edit-lock release fixes found by CI.

- News list: the search box was squeezed to 86px at 1440px; the toolbar now stacks until 2xl. Flex `summary` elements get a drawn chevron so collapsed sections read as expandable.
- Home «my work»: cards with work lead, empty ones become slim lines; create buttons follow permissions; dates read in the station format (today / tomorrow / full date); the duplicate clock in the hero is hidden where the top bar shows it.
- Bulletin readiness: one row per story with worded «مانع/تنبيه» chips (not colour alone), owner beside them, blockers first.
- On-air: the offline-copy form is collapsed (shows how many copies are saved); an empty rundown explains itself and why Start is disabled; the status badge no longer wraps on phones.
- News editor: the headline wraps instead of scrolling sideways; the breaking-ticker preview opens on demand (automatically for breaking news).
- Broadcast schedule on phones: empty days are compact; coverage start dates use the station format.
- Edit locks: leaving or reloading while a lock request is in flight, or reloading and leaving at once, no longer leaves a lock that blocks colleagues (see 3.25.0 follow-ups: owner-only `POST /api/v1/data/locks/release`, per-tab record of held locks released on the next load).
- What's New, package, server health and rehearsal report versions match 3.26.0.

Verification: TypeScript, unit tests, production build and the full browser suite (see the pull request or CI for the exact run on the release commit).
