# مدار v4.7.0

## وحدات النظام

تتيح **الإعدادات ← وحدات النظام** تشغيل وحدات العمل وإيقافها على مستوى المؤسسة، وتخصيص الإتاحة بحسب المحطة والقسم والدور والحساب. يستطيع المدير البدء بقالب للتكليفات أو غرفة الأخبار أو إنتاج البرامج، ومعاينة أثره على موظف، واستعادة سياسة سابقة من سجل المراجعات.

## استمرار العمل

- يمكن إيقاف المساعد التحريري مع استمرار التحرير اليدوي، أو إيقاف التفريغ الآلي مع استمرار الوصول إلى الوسائط المصرح بها.
- يتيح وضع إنهاء العمل القائم متابعة التكليفات المسندة مع وقف إنشاء تكليفات جديدة.
- يحمي الخادم جلسات البث القائمة من تغييرات الإتاحة التي قد تقطعها. وتبقى الوسائط المرتبطة بعمل مصرح به متاحة عند إيقاف تصفح المكتبة.

تحتفظ المنشآت التي حدّدت إتاحة البرامج والتكليفات بإعداداتها عند التحديث. تطبّق الجلسات المتصلة تغييرات الإتاحة عبر المزامنة. [دليل لوحة الوحدات](../superpowers/plans/2026-11-26-modular-workspaces.md#استخدام-لوحة-الإدارة)
