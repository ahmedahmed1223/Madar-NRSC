# مدار 5.0.2

- يعرض «تنبيهاتي» سجل الإشعارات المتاحة للحساب، مع تصفية غير المقروءة وإظهار الدفعات الأقدم بجانب إعدادات التنبيه.
- تظهر المهام المكتملة والملغاة ضمن الدفعة الأولى في وضع القائمة عند توفّرها في النتائج، حتى مع كثرة المهام الجارية. يظل التصفّح متاحًا لاستعراض بقية المهام.
- تعرض صفحة «ما الجديد» تفاصيل الإصدار الخامس حسب القسم، وتشمل إدارة الصلاحيات والوسائط والتخزين وسلة المحذوفات والنسخ الاحتياطي.

## التحديث

استخدم حاوية هذا الإصدار مع إعدادات التشغيل ووحدات التخزين الحالية. راجع [دليل تشغيل الإنتاج](../PRODUCTION_OPERATIONS.md) و[ملاحظات 5.0.1](../releases/5.0.1.md).
