# مدار v4.3.5

- اختر التذكير عند موعد التسليم أو قبله بـ15 دقيقة أو ساعة أو يوم. ويمكن تفعيل تنبيه منفصل بعد تأخر الموعد بـ15 دقيقة.
- تصل التنبيهات إلى المكلف بالمهمة وصاحب القرار في التكليف والمكلفين بخطواته بحسب مواعيدهم. يفتح إشعار الجرس العمل المعني مباشرةً.
- يعيد الخادم الجدولة عند تعديل الموعد أو المكلف، ويوقف التنبيهات عند الإنجاز أو الإلغاء. يظهر تغيير موعد تسليم التكليف أو إحدى خطواته في الإشعارات.
- تعرض قوائم الإسناد الزملاء المؤهلين. يتحقق الخادم من المستوى الإداري ونطاق المحطات، ويبقى إسناد رئيس القسم للمهام ضمن فريقه.
- ينشئ ترحيل قاعدة البيانات جدول التذكيرات وفهرسه مع الاحتفاظ بالسجلات الموجودة.
