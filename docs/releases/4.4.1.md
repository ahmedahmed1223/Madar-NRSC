# مدار v4.4.1

- يبدأ معالج التهيئة الأولى من صفحة الدخول. يتيح إنشاء حساب المسؤول وتغيير كلمة المرور المؤقتة. تظهر تلميحات الحسابات التجريبية عند تمكينها.
- يحدد مسؤول النظام إتاحة البرامج والتكليفات للجميع أو لمستخدمين وأدوار محددة، ويمكنه تعطيل كل قسم.
- تبقى SQLite قاعدة البيانات الافتراضية. يمكن استخدام PostgreSQL بإعداد `POSTGRES_URL` على الخادم، وجدولة نقل السجلات بين المحركين عند إعادة التشغيل. يتحقق التطبيق من البيانات المنقولة ويحتفظ بالقاعدة الأصلية.
- عند ترحيل هيكل قاعدة SQLite قائمة، ينشئ التطبيق لقطة قبل الترحيل ويطبّق التعديلات في معاملة واحدة. تستمر عمليات التحديث باستخدام مجلد `DATA_DIR` الدائم نفسه لحفظ البيانات والمرفقات وإعداد المحرك.

تجد خطوات التحديث ونقل قاعدة البيانات في [دليل التشغيل](../PRODUCTION_OPERATIONS.md).
