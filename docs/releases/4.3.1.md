# مدار v4.3.1

- يفتح معالج الإعداد تلقائياً في التثبيت الجديد عند أول دخول بحساب يملك صلاحية إعدادات النظام، ويظهر مجدداً بعد حذف البيانات التجريبية.
- تعرض خطوة المؤسسة الاسم والقناة والمنطقة الزمنية ونظام الساعة وتوقيت المواعيد. تُحفظ التعديلات عند اعتمادها، وتبقى إعدادات المؤسسة وحساباتها الفعلية محفوظة عند حذف الأمثلة.
- تتيح خطوة حساب المسؤول متابعة الإعداد بالحساب الحالي أو إنشاء مسؤول مؤسسي بكلمة مرور مؤقتة يغيّرها عند أول دخول.
- يمكن تأجيل الإعداد والرجوع إليه من «المساعدة ← الإعداد السريع للنظام».
